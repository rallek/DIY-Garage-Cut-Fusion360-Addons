# Projektübersicht

Stand: 2026-05-17 18:45 UTC

## Ziel

Fusion-360-Addins für DIY Garage Cut.

Fusion liefert:
- Geometrie
- Fertigmaße
- Fertigungsmetadaten

DIY Garage Cut verarbeitet:
- Rohmaße
- Zuschnitt
- Kantenbedarf
- Labels
- QR-Codes

## Addins

| Addin | Zweck |
|---|---|
| DIYGarageCutExportAddin | Export + Analyse + Katalog |
| DIYGarageCutPropertiesAddin | Body-Eigenschaften |
